# Welcome screen art

Three PNGs in this folder power the onboarding carousel:

| File | Slide |
|------|-------|
| `welcome-1-video.png` | Connect with your physiotherapist |
| `welcome-2-exercise.png` | Guided movement at home |
| `welcome-3-progress.png` | See your rehab journey |

Replace these files and restart Metro (`npm run start:dev`) to preview. No dev rebuild required.
