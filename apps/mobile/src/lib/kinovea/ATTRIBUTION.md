# Kinovea-derived posture data

The human model topology (joint names, segment colors, default standing pose) is adapted from Kinovea's open-source custom tool:

- Source: [Kinovea/Kinovea](https://github.com/Kinovea/Kinovea) — `Tools/DrawingTools/Custom/10 - Human model.xml`
- Project: [kinovea.org](https://www.kinovea.org/features.html)

Stride uses this only as **static reference geometry** for the demo form-guide panel and alignment-guide proportions. Live skeletal tracking remains MediaPipe BlazePose on the camera feed.
